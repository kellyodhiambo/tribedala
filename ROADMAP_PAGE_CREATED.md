## 🔧 HOW TO USE

1. **Start your dev server**:
   ```bash
   npm run dev
   ```

2. **Go to the roadmap page**:
   ```
   http://localhost:5173/roadmap
   ```

3. **View and interact**:
   - Click cards to expand/collapse
   - Check off tasks as you complete them
   - Review critical issues
   - Plan your sprints
