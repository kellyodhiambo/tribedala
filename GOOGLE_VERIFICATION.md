## 🔍 Troubleshooting

### Issue: Verification Says Meta Tag Not Found

**Solution:**
1. Rebuild: `npm run build`
2. Redeploy to production
3. Wait 5-10 minutes
4. Clear browser cache (Ctrl+Shift+Delete)
5. Check page source again
6. Retry verification

### Issue: Can't Find Meta Tag in Page Source

**Solution:**
1. Go to: https://tribedala.com
2. Right-click → "View Page Source" (not Inspect)
3. Press Ctrl+F to search
4. Search for: `google-site-verification`
5. Should find the meta tag

### Issue: Getting 404 Error

**Solution:**
1. Check site loads at: https://tribedala.com
2. Verify deployment successful
3. Check .htaccess not blocking
4. Check /public files are served

### Issue: Verification Stuck

**Solution:**
1. Wait 24-48 hours
2. Try HTML file method as backup
3. Check Google Search Console for specific error
4. Contact Google Support if needed
