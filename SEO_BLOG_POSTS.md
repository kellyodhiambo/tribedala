## Blog Content Optimization Guidelines

### SEO Structure for Each Post

1. **Title Tag** (50-60 characters)
   - Include primary keyword
   - Action-oriented or curiosity-driven
   - Benefit-focused

2. **Meta Description** (155-160 characters)
   - Primary keyword mention
   - Clear value proposition
   - CTA implied

3. **Slug** (SEO-friendly, lowercase, hyphens)
   - Keyword-rich
   - Readable
   - Not too long

4. **H1** (One per page)
   - Primary keyword
   - Compelling heading

5. **H2/H3 Hierarchy**
   - Secondary keywords
   - Logical structure
   - 3-5 subheadings per 1000 words

6. **Internal Links** (3-5 per post)
   - DALA main event page
   - Ticket booking pages
   - Related blog posts
   - Artist profile pages
   - Information pages

7. **External Links** (2-3 per post)
   - Authority sources
   - Tourism sites
   - Government resources
   - Industry publications

### Content Best Practices

- **Length**: 1,500-3,500 words for main posts
- **Readability**: Flesch-Kincaid Grade 8-10
- **Images**: 2-5 per post, optimized with alt text
- **Videos**: 1 embedded video if available
- **Lists**: Use bullet points and numbered lists
- **Tables**: Use for comparisons
- **FAQ Section**: Common questions about topic
- **Call-to-Action**: Clear next steps

### Keyword Integration

- **Primary Keyword**: In title, H1, first 100 words
- **Secondary Keywords**: In H2, body text (natural)
- **LSI Keywords**: Related terms throughout
- **Keyword Density**: 1-2% (natural, not forced)
- **Synonyms**: Use variations naturally

### Meta Tags for Blog Posts

```html
<meta name="description" content="[155-160 char description with primary keyword]">
<meta name="keywords" content="primary keyword, secondary keyword, tertiary keyword">
<meta property="og:title" content="[Title optimized for social]">
<meta property="og:description" content="[Social-optimized description]">
<meta property="og:image" content="[Featured image URL]">
<meta name="twitter:card" content="summary_large_image">
<link rel="canonical" href="https://tribedala.com/blog/[slug]">
```
